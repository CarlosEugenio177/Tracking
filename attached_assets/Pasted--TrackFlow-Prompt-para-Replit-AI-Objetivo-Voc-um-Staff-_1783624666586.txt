# 🚀 TrackFlow — Prompt para Replit AI

## Objetivo

Você é um **Staff Software Engineer**, **Product Manager**, **Software Architect** e **UX Designer** especialista em **SaaS**, **Marketing Analytics**, **Tracking Digital** e **Micro SaaS**.

Sua missão é construir um produto completo, moderno, escalável e preparado para produção.

---

# 📌 Visão do Produto

Quero desenvolver um **Micro SaaS chamado TrackFlow** (nome provisório).

O objetivo é ser o **"GitHub do Tracking Digital"**, centralizando toda a jornada de uma campanha:

```
Campanha
      ↓
Gerador de UTM
      ↓
Link Compartilhado
      ↓
Clique
      ↓
Landing Page
      ↓
Webhook
      ↓
CRM
      ↓
Venda
      ↓
ROI
```

O produto **não será apenas um gerador de UTMs**.

Ele deve resolver problemas reais enfrentados por:

- Gestores de Tráfego
- Agências
- Empresas
- Analistas de Marketing
- Analistas de BI

Inicialmente será voltado para o mercado brasileiro, mas toda a arquitetura deve ser preparada para internacionalização.

---

# 🎯 Problemas que queremos resolver

Hoje o mercado sofre com:

- UTMs sem padronização
- campanhas desorganizadas
- links espalhados
- perda de histórico
- ausência de governança
- campanhas publicadas sem UTM
- dificuldade para descobrir qual anúncio gerou uma venda
- números diferentes entre Meta Ads, Google Ads, GA4 e CRM
- tracking quebrado
- webhooks difíceis de analisar
- ausência de auditoria
- dificuldade para debugar eventos
- dificuldade para medir ROI real

O sistema deve resolver essas dores.

---

# ⭐ Diferencial

O TrackFlow acompanha **todo o ciclo do tracking**, desde a criação da campanha até o fechamento da venda.

Não queremos competir apenas com geradores de UTM.

Queremos criar uma plataforma completa de governança e observabilidade do tracking.
